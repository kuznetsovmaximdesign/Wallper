# Требование (Максим, 29.10.2026): таблица ответов продавцов

Если мы уже писали продавцу — его ответ записывается в таблицу.
Только сжатая полезная суть, весь лишний текст отсекаем (приветствия, «здравствуйте»,
реклама, подписи, шаблонные фразы).

## Формат строки (одна строка = один продавец + одно объявление)
| Поле | Что пишем | Пример |
|---|---|---|
| seller_key | ключ продавца | brands:bas500 |
| item_id | объявление, по которому писали | 4347780205 |
| статус | ответил / не ответил / отказал / просит позвонить | ответил |
| дата ответа | ДД.ММ ЧЧ:ММ | 29.10 14:05 |
| цена | число, ₽, и за что (под ключ / за единицу) | 85000, под ключ |
| срок | дней / дата выезда | 3 дня |
| что входит | ≤ 80 символов, через запятую | септик, доставка, монтаж |
| условия | предоплата, гарантия, выезд на замер | предоплата 30%, гарантия 5 лет |
| контакт | телефон/мессенджер, если дали | +7… |
| след. шаг | одно действие | звонить завтра |
| диалог | ссылка на чат | — |

## Правила
- Нет данных → «—», не придумывать.
- Исходный текст ответа в таблице не хранить (максимум — ссылка на диалог).
- Повторный ответ того же продавца обновляет строку (старые значения не копить).
- Числа — только цифрами, без «примерно/от», кроме явного «от» в поле цены.
