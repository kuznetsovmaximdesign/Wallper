# Разметка Авито (разведка 27.10.2026, мини-ПК, домашний RU-IP)

CSS-классы хешированные — опора на `data-marker`, `data-item-id`, `href`.

## Доступ
- curl → 429 «Доступ ограничен: проблема с IP» (отпечаток curl, не IP).
- Chromium (Playwright, с окном в Xvfb, без прокси): главная 200, объявление 200,
  профиль 200; выдача — **439**, но страница целиком (мягкая метка антибота).
- XHR списка объявлений на профиле не прошёл («Не удалось выполнить поисковой запрос») —
  вероятно, тот же мягкий лимит.

## Выдача `/<город>/<категория>?q=…&p=N`
```
catalog-serp → item[data-item-id], id="i<id>"
   item-title (ссылка) / item-price-value / item-location
   item-link — имя продавца, href /brands/<slug>?iid=…&src=search_seller_info
   seller-rating/score — «4,9»
   seller-info/summary — «74 отзыва Реквизиты проверены»; бейджи badge-title-<id>
   item/grouping — «Ещё N похожих», sellerId=<hex32> (у ~7 из 49 карточек)
page-title/count — всего; pagination-button/page(N), /nextPage; не больше ~11 страниц
```
- ~49 карточек на страницу; ссылка на продавца у 48 из 49.
- Ссылок `/user/…` нет. Slug продавца: `i<цифры>`, hex32 или текст.
- JSON с карточками внутри страницы нет (только A/B и категории).

## Объявление
JSON `window.__preloadedState__`: `userKey` (hex32), `userId`, `sellerName`,
`shopInfo.isShop`, `profileUrl`, `rating.{scoreFloat, summary, activeReviewsCount}`,
`publicProfileInfo.howOldInfo` («На Авито с …»). `shopId` — только в ссылках на профиль.
«71 отзыв клиента» внизу объявления — отзывы этого объявления, не общий счётчик (общий — 74).

## Профиль `/brands/<slug>`
```
profile — <h2> имя, <p> «На Авито с … ∙ подписчики»
profile/score, profile/summary, badge-bar → badge-<id>
extended_profile_tabs/tab(active|closed) — счётчики объявлений
item_list_with_filters/show_all_button → /brands/<slug>/items
```
Объявления на профиле приходят XHR, в исходном HTML их нет.

Бейджи: 2360/2361 «Реквизиты проверены», 31 «Документы проверены»,
2772 «Надёжный исполнитель», 2839 «#яПомогаю».

## Выводы
- Ключ продавца — slug из `/brands/<slug>` (есть почти у всех карточек); hex32
  `userKey` надёжнее, но в выдаче есть редко.
- Рейтинг, отзывы, проверки — прямо из выдачи; профиль нужен только для «На Авито с».
- Мягкий лимит (439) — нужен тест частоты и «прогрева».
