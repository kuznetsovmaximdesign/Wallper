# Avito Scout — план (на согласование)

> **Отдельный проект.** Живёт только в папке `avito-scout/` и не связан с Wallper.
> Единственное касание снаружи — строка `avito-scout/**` в `paths-ignore` у
> `.github/workflows/android.yml`, чтобы коммиты сюда не запускали Android-сборку.
> Перенос в свой репозиторий: `git subtree split --prefix=avito-scout -b avito-scout`
> → push в новый репо (история сохранится), затем удалить папку и эту строку здесь.

## 1. Что делает сервис

Веб-сервис (адаптивный, телефон + десктоп, ставится как PWA), один пользователь — вы.

1. **Задача** — например «Сборка кухни», с описанием, фото и критериями.
2. **Где искать** — адрес/точка на карте + радиус (км), *или* готовая ссылка поиска
   Авито с вашими фильтрами (можно несколько).
3. **По чему искать** — ваши запросы («сборка кухни», «сборщик мебели», …) +
   «умный поиск»: ИИ по описанию задачи предлагает дополнительные запросы и
   отсеивает нерелевантные объявления (продажа товаров, другие услуги и т. п.).
4. **Критерии** — рейтинг ≥ X, отзывов ≥ N, опционально: частник/компания,
   «на Авито с …», подтверждённые документы, цена «от/до».
5. **Таблица исполнителей** — одна строка = одна учётка (не объявление):
   имя, рейтинг, число отзывов, на Авито с, все его найденные объявления, цены,
   расстояние, ссылка на профиль, статус переписки. Сортировка, фильтры, экспорт в
   Excel/CSV, ручные пометки («избранное», «не подходит»).
6. **Рассылка** — выбираете исполнителей → сервис пишет каждому по шаблону задачи;
   если фото нельзя приложить к первому сообщению — отправляет после первого ответа.
   Ответы видны в сервисе, статус в таблице: *не писали → отправлено → ответил →
   фото отправлено → договорились / отказ*.

## 2. Ключевые ограничения Авито (честно)

| Вопрос | Реальность | Что делаем |
| --- | --- | --- |
| Публичный API поиска | Нет. Официальный API Авито — для продавцов (свои объявления, свои чаты). | Поиск через браузер-робота (Playwright) по страницам сайта. |
| Антибот | Авито блокирует зарубежные и «серверные» IP, показывает капчу при частых запросах. | Сервер/прокси с российским IP, медленный темп, кэш; капча → уведомление вам. |
| Написать исполнителю | Новый чат создаётся только с сайта/приложения покупателем; через API — нельзя. | Робот работает под **вашей** учёткой Авито (вход один раз, сессия хранится). |
| Фото в первом сообщении | Нужно проверить на этапе 0. | Правило «фото сразу, если можно, иначе — после ответа». |
| Антиспам | Массовые одинаковые сообщения → ограничение/бан учётки. | Лимит новых чатов в день (старт ~10–15), паузы, вариации текста, ручное подтверждение пачки. |
| Правила Авито | Автоматический сбор и рассылка запрещены пользовательским соглашением — риск блокировки учётки. | Темп «как человек», лимиты; рекомендую отдельную учётку для рассылок. |

## 3. Дедупликация

Ключ — **ID профиля продавца** из ссылки `avito.ru/user/<id>/profile` (или
`/brands/<id>`): это точнее, чем имя (имена повторяются, «Александр» — тысячи).
Запасной ключ, если ID не удалось достать: имя + рейтинг + число отзывов +
«на Авито с». Все объявления одной учётки сворачиваются в одну строку.
Уже отклонённые/написанные исполнители помечаются и в новых поисках не всплывают
повторно как новые.

## 4. Архитектура

```
avito-scout/
  web/        фронтенд: React + Vite, PWA, адаптивная таблица
  server/     API: Node.js (TypeScript, Fastify), авторизация, очереди
  worker/     Playwright-робот: поиск, профили, чаты, отправка
  shared/     типы и схемы
  docs/       заметки по разметке Авито, результаты этапа 0
```

- **БД:** SQLite (одного пользователя хватает; потом легко Postgres).
- **ИИ:** Claude API — расширение запросов, оценка релевантности объявления,
  вариации текста сообщения.
- **Хостинг:** VPS в России (Timeweb/Selectel, ~500–1000 ₽/мес) — нужен российский IP;
  при блокировках — резидентный/мобильный прокси (отдельный бюджет).
- **Доступ:** вход по паролю/ссылке, HTTPS, домен или поддомен.
- **Уведомления:** Telegram-бот — «исполнитель ответил», «нужна капча», «поиск готов».

## 5. Этапы

| # | Этап | Результат | Ваше участие |
| --- | --- | --- | --- |
| 0 | **Разведка** (1–2 дня) | Скрипт с российского IP: поиск с радиусом, парсинг карточек и профиля (рейтинг, отзывы), создание чата, отправка текста и фото. Отчёт: что работает, лимиты, капчи. | Тестовая учётка Авито, где запустить (VPS/ваш ПК). |
| 1 | **Поиск + таблица** | Задачи, запросы/ссылки, локация+радиус, критерии, дедуп, таблица, экспорт, мобильная вёрстка, деплой. | Проверить на реальной задаче. |
| 2 | **Умный поиск** | ИИ-расширение запросов, фильтр нерелевантного, оценка «насколько подходит». | Отметить ошибки ИИ. |
| 3 | **Рассылка** | Шаблоны, отправка с лимитами, фото после ответа, входящие, статусы. | Утвердить тексты и лимиты. |
| 4 | **Удобства** | Telegram-уведомления, повторный поиск по расписанию (новые исполнители), заметки. | — |

Каждый этап — отдельный PR, после этапа 0 план уточняется по фактам.

## 6. Нужно решить до старта

1. **Где запускать робота:** VPS в РФ (работает 24/7, нужен прокси при блоках) или
   ваш компьютер с российским IP (надёжнее против антибота, но должен быть включён).
2. **Учётка Авито для рассылки:** основная или отдельная.
3. **Отправка:** полностью автоматическая с лимитами или «робот готовит —
   вы жмёте „отправить пачку“» (рекомендую второе на старте).
4. **Бюджет:** VPS, прокси (если понадобится), Claude API (копейки на запрос).
5. **Название** (рабочее — Avito Scout) и домен.
