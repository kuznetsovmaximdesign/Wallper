# Wallper — 4K видеообои для Android

Живые видеообои в духе экранов Apple: оригинальные аэросъёмки **Apple Aerials** (заставки
Apple TV) или ваши собственные видео, превращённые в бесшовную петлю до 30 секунд.

## Возможности

- **Каталог Apple Aerials** — 100+ сцен (пейзажи, подводный мир, космос, города) в исходном
  4K HEVC. Каталог и видео загружаются напрямую с серверов Apple на устройство.
- **Без потери качества** — выбранный фрагмент (до 30 с) вырезается без перекодирования:
  копируется исходный 4K-поток. Скачивается только нужный фрагмент (HTTP range), а не
  весь файл в сотни мегабайт.
- **Бесшовная петля** — два аппаратных декодера и GPU-кроссфейд прячут стык цикла.
- **Скорость 0.25×–2×** для каждых обоев отдельно.
- **Складные смартфоны** — один общий сеанс воспроизведения на все экраны: при
  складывании/раскладывании видео продолжается с того же кадра; кадрирование
  подстраивается под любой формат экрана; интерфейс list-detail на внутреннем экране.
- **Кадрирование** — перетащите кадр в превью, чтобы выбрать композицию.
- **Параллакс** при листании рабочих столов, Material You цвета системы из кадра видео,
  пауза при энергосбережении.
- **Своё видео** — из галереи через системный Photo Picker.

## Архитектура

| Слой | Что внутри |
| --- | --- |
| `core` | Модели (`Footage`, `Clip`, `Focus`), правила продукта (`Playback`) |
| `data` | Каталог Apple (tar-манифест → JSON), библиотека клипов, настройки (DataStore) |
| `net` | OkHttp + `AiaTrustManager` (достраивает цепочку сертификатов Apple CDN, как браузер) |
| `media` | Range-источник для `MediaExtractor`, нарезка без перекодирования, обложки |
| `playback` | `LoopRenderer` (OpenGL ES 3, OES-текстуры, cover-crop, кроссфейд, дизеринг), `LoopSession` (2× ExoPlayer), `PlaybackHub` (общий сеанс для экранов Fold) |
| `wallpaper` | `WallpaperService` на GLSurfaceView |
| `work` | Подготовка клипа в WorkManager с foreground-уведомлением |
| `ui` | Jetpack Compose, Material 3, адаптивный layout |

Стек: Kotlin 2.0, Jetpack Compose (BOM 2024.12), Media3 ExoPlayer 1.5, WorkManager,
DataStore, Coil 3, kotlinx.serialization. minSdk 29, targetSdk 35.

## Сборка

```bash
./gradlew assembleRelease   # app/build/outputs/apk/release/
./gradlew testReleaseUnitTest lintRelease
```

CI (GitHub Actions) на каждый push собирает подписанный APK и публикует его в Releases.
Ключ подписи `keystore/wallper.jks` хранится в приватном репозитории для личного
использования: каждая новая сборка ставится поверх предыдущей.

## Правовая оговорка

Приложение предназначено для личного использования. Видео Apple Aerials принадлежат Apple
и не хранятся в репозитории и не входят в APK — приложение загружает их на устройство
пользователя с публичного CDN Apple, как это делают open-source проекты Aerial/Aerial Views.
